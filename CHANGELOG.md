# Changelog

## Unversioned
- Minor: Every change to the main branch is published as the Nightly Release on GitHub, and nightly builds say "Nightly" after their version.
- Minor: Builds include the licences of the software they bundle (THIRD-PARTY-NOTICES.txt).
- Minor: Only one of two mods that change the same files can be on. Turning one on turns the other off, with Undo, and a warning shows which mods clash.
- Minor: The mods page can be sorted by newest, most liked, most viewed or most downloaded, as well as by recent activity.
- Minor: Installed mods with files uploaded to GameBanana since you installed them are marked, and those files are marked "New", which can be dismissed, when choosing which version to use.
- Minor: The markers on mod pictures for clashing and merged mods are solid, so they show on any picture.
- Minor: Messages at the top of the window wrap long text instead of cutting it off, and stay up while the pointer is over them.
- Bugfix: Mods in the older version 1 VPK format, and mods whose VPK lists an empty file at an unusual position, now install.

## 0.2.0
- Minor: Show the version in the window title.
- Minor: Show the version, commit, Qt version and system in Settings › Advanced.
- Bugfix: Fix game status detection inside of Flatpak.
